# 待办（下一版本）

记录已知但未在当前版本处理的问题，按版本追加。处理后移入 CHANGELOG 并从这里删除。

## 3.0.12 遗留

- **左导航高亮跳到「我的」**：宽屏从单豆「评分与记录」页打开「手冲回顾」时，左侧导航高亮切到「我的」，关闭回顾后才回到「豆仓」。期望打开期间保持「豆仓」高亮。
- **宽屏中栏卡片上方空白带**：≥1100 时中栏列表在第一张卡片上方有一段空白（打开或关闭详情都存在，非 3.0.12 引入），待视觉给出设计后处理。
- **`data-layer-over-detail` 关闭时未清除**：侧页关闭后该标记仍留在 dialog 上，下次打开会重新计算，目前无可见影响；可在关闭路径上顺手清理。

## 3.0.14 遗留

- **滚轮字段无法清空**：水温、粉量、总水量等滚轮字段只能选数字，界面上没有「清空」入口，已有值无法清成空（非 3.0.14 引入）。后续作为所有滚轮字段的统一能力处理，交互和样式待视觉给出设计。3.0.14 已有的「用户主动清空才写空」代码逻辑保持不变，届时直接接上即可。
- **「常用水温」只统计区间的第一个数**：手冲回顾 / 洞察里的常用水温把区间水温（如 90-92°C）按 90 计入，区间上限和中间值都不参与统计；非数字文本（常温）不计入。后续决定区间的统计口径（下限 / 中值 / 上下限都计）。

## 3.0.15

- **滚轮方向键跳值**：键盘操作滚轮时（↑ / ↓），平滑滚动与按键事件互相打架，出现跳值（例如 93 → ↓ 得到 92，再按又变 94）。触屏点选与滑动正常，仅影响键盘路径（QA 3.0.14 报告第 5 条）。
