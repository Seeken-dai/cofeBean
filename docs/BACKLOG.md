# 待办（下一版本）

记录已知但未在当前版本处理的问题，按版本追加。处理后移入 CHANGELOG 并从这里删除。

## 3.0.14 遗留

- **滚轮字段无法清空**：水温、粉量、总水量等滚轮字段只能选数字，界面上没有「清空」入口，已有值无法清成空（非 3.0.14 引入）。后续作为所有滚轮字段的统一能力处理，交互和样式待视觉给出设计。3.0.14 已有的「用户主动清空才写空」代码逻辑保持不变，届时直接接上即可。

## 3.0.16 候选（3.0.15 测试后记录）

- **饮用详情右栏窄容器单列**：右栏容器宽度小于约 560px 时，卡片收成单列。3.0.15 没做，因为在约 1100–1136px 窗口宽度会破坏「有评分有备注」状态与 3.0.14 像素一致的要求。做的时候要重新确认该状态的像素对比。
- **无评分无备注时「冲煮参数」卡不拉伸**：给该卡加 `align-self:start`（3.0.15 中它被拉伸到 234px，原来 193px）。「有评分有备注」布局依赖卡片拉伸，改之前要验证该状态像素不变。
- **宽屏「评分与记录」子页分隔线错位 20px**（测试 P3·O1）：中栏分隔线 y=72，右栏 y=92（3.0.14 基本对齐）。待视觉确认是否需要对齐。
- **常用水温口径**（测试 P3·O2）：「200°F」会被当成 200°C 计入；「95-100」这类区间的中值可能超过 100。待产品定口径（换算华氏、设上限或不计入）。
