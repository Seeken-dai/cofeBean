# 豆仓 3.0 页面覆盖矩阵

本表是 3.0 纯视觉改版的实现与验收基线。产品能力、字段、数据结构和同步语义以 2.4.3 实现为准；视觉稿只提供布局与视觉语言。第 02 章“开始使用”保持为独立议题，本轮不实现也不借机引入器具档案等新能力。

## 主视图

| 当前界面 | 视觉稿参考 | 手机 `<1100px` | 宽屏 `≥1100px` | 必验状态 |
| --- | --- | --- | --- | --- |
| 豆仓 `#beansView` | 2a、7a、8b/8c/7e、13a | 大标题、概览、分段筛选、标签卡片、底部导航 | 侧栏、常驻搜索/筛选、自适应卡片网格 | 有数据、空仓、搜索、筛选无结果、提醒、低余量、无图片 |
| 饮用 `#drinksView` | 3a、7b、11a、13c/9c | 概览、分段筛选、时间线、底部导航 | 侧栏、时间线主区、详情右栏 | 自冲、外饮、待补感受、空记录、加载更多、照片 |

## 公共状态

- 四主题：深烘、澳白、火山灰绿、生豆；所有表面、文字、边框、焦点和语义色必须由 Token 派生。
- 尺寸：360、390、760、1099、1100、1440；1099 与 1100 分别验证两档外壳切换。
- 能力：默认离线、同步关闭、同步异常、相机不可用、图片缺失、旧数据缺字段、计划开关关闭。
- 交互：键盘焦点、触控 48dp、文本溢出、安全区域、软键盘、长列表滚动、减弱动效、Android 返回层级。

## 本轮交叉核对结论

- 第 03 章：豆子详情已补齐核心库存指标、风味画像、最近冲煮、绑定方案和宽屏“列表 + 详情”；“喝一杯”按 12d 改为半屏快捷记录，并保留进入完整记录的入口。
- 第 07 章：已补齐全屏分组搜索、手机筛选抽屉、生效筛选芯片、筛选无结果操作和宽屏常驻筛选栏。
- 第 08 章：已重做“我的”总览与设置二级页；宽屏设置使用侧栏分类与卡片内容区。视觉稿里的器具、心愿单和密度字段仍按范围约束排除。
- 第 09 章：已补豆仓卡片骨架、启动失败恢复、搜索无结果和筛选无结果；删除仍使用现有二次确认，不实现视觉稿中的撤销语义。
- 其余章节复核后，冲煮、记录、评价、日历、回顾、报告、备份以及宽屏编辑/计时工具均有现有功能承载；与稿件仍不同的项目都落在下方“明确不实现”或第 02 章议题中。

## 明确不实现

引导向导、器具/磨豆机实体、愿望单、结构化风味轮、分段实测对比、通知中心、自动备份、CSV、备份历史、杯型/温度、撤销删除、昵称或用户档案。视觉稿中的这些内容不能转化为字段、入口或数据模型。
